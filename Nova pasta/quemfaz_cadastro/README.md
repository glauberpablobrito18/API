# QuemFaz — Tela de Cadastro

Tela de cadastro responsiva seguindo a mesma identidade visual da tela de login.

Arquivos:
- index.html
- style.css
- script.js

Campos:
- Nome
- Sobrenome
- E-mail
- Telefone com máscara
- Senha
- Confirmação de senha
- Aceite dos termos

A validação funciona no navegador. O envio ainda é demonstrativo; para autenticação/cadastro real, conecte o formulário a um backend/API.
