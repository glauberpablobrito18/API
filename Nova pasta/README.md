# QuemFaz — Tela de Login

Tela de login responsiva criada em HTML, CSS e JavaScript, seguindo a identidade visual da imagem enviada:

- Azul-marinho
- Laranja
- Fundo creme
- Tipografia e espaçamentos semelhantes
- Logo/identidade "QuemFaz"
- Formulário de e-mail e senha
- Mostrar/ocultar senha
- Validação dos campos
- "Esqueci minha senha"
- "Manter conectado"
- Botão de login
- Botão de login com Google
- Layout responsivo para celular

## Como executar

Abra o arquivo `index.html` no navegador.

A autenticação está simulada no JavaScript. Para colocar login real, substitua o trecho indicado em `script.js` por uma chamada à sua API/backend.
