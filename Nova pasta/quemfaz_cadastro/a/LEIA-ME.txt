QUEM FAZ — TEMPLATE DE PÁGINA DE PROFISSIONAIS

ARQUIVOS
- index.html: estrutura da página.
- styles.css: todo o design responsivo. Você pode manter igual para todas as profissões.
- config.js: textos, imagem principal e lista de profissionais. É o arquivo que você altera para cada profissão.
- script.js: pesquisa, filtros e renderização dos cards.

COMO USAR
1. Extraia a pasta do ZIP.
2. Abra index.html no navegador para testar.
3. Para criar uma página para outra profissão, edite config.js:
   - titleHighlight e description;
   - servicePlaceholder, listTitle e textos de disponibilidade;
   - heroImage;
   - os objetos dentro de professionals (nome, função, avaliação, cidade, disponibilidade, preço, imagem e contato).
4. Mantenha os nomes das propriedades e a estrutura do objeto. O CSS não precisa ser alterado.
5. Os dados são exemplos demonstrativos. Troque nomes, preços, avaliações e contatos por dados reais antes de publicar.
6. As imagens usam URLs externas do Unsplash e precisam de internet para carregar.
7. O botão de contato é demonstrativo e mostra um alerta. Para um sistema real, conecte-o ao WhatsApp, formulário ou backend.

DICA
Duplique a pasta para cada profissão ou mantenha uma única página e substitua apenas config.js. Para publicar, envie os quatro arquivos para uma hospedagem estática, como GitHub Pages, Netlify ou Vercel.
